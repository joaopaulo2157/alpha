Segurança da V9

O painel usa autenticação do Supabase. A chave pública do navegador não substitui as políticas RLS. Execute o arquivo schema.sql no SQL Editor do Supabase antes de ativar a sincronização.

Exportar backup

Salva catálogo, pedidos, clientes, estoque, cupons e configurações em um arquivo JSON.

Importar backup

Restaura uma cópia exportada anteriormente. Os dados atuais serão substituídos.

Restaurar padrão

Apaga os dados locais da V3 e volta ao catálogo inicial.

Sobre esta V9

A V9 funciona em modo híbrido: mantém uma cópia local para resiliência e, quando o Supabase está configurado, sincroniza catálogo, pedidos, clientes, estoque e configurações entre dispositivos.
